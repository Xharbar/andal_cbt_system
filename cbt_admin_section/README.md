# cbt_admin_section

The **Admin Section** of the CBT system is the central hub where administrators manage students, teachers, exams, and data. It allows secure login, creation of student profiles with unique exam passcodes, collection and organization of student scores by subject, retrieval of teacher-uploaded questions and configurations from the server (with offline availability during exams), and creation of teacher profiles with subject assignments. All data is synchronized with the server to ensure smooth exam operations and reliable record-keeping.
